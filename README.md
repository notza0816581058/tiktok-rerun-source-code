# TikTok Rerun Source Code (Live Hub demo)

ตัวอย่างหน้าเว็บของ **Live Hub** ระบบจัดการไลฟ์รีรันบน TikTok สำหรับหลายบัญชี
repo นี้มีหน้าเว็บครบทุกหน้าและรันบนเครื่องได้ แต่ใช้ **ข้อมูลตัวอย่างทั้งหมด** และ **ไม่เชื่อมต่อระบบจริง**

> Demo of the Live Hub console (Next.js 16 + React 19). Every page works on localhost with
> invented sample data. All real integrations were removed, so it cannot run a real LIVE.

## รันบนเครื่อง

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:3100 แล้วล็อกอินด้วย

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| ผู้ดูแล (เห็นทุกเมนู) | `demo` | `demo` |
| ทีมงาน | `staff01` | `demo` |

ข้อมูลเก็บในหน่วยความจำ ปิดแล้วเปิด dev server ใหม่ ข้อมูลจะกลับเป็นค่าเริ่มต้น

## มีอะไรให้ลองบ้าง

| หน้า | ลองทำอะไรได้ |
|---|---|
| บัญชีไลฟ์ | ดูการ์ดบัญชี ยอดขาย GMV, กดเริ่ม/ลงไลฟ์ (เปลี่ยนสถานะบนจอเท่านั้น), เปิดหน้าต่างตะกร้าสินค้าและตั้งค่าไลฟ์ |
| คลังวิดีโอ | อัปโหลดไฟล์ (ระบบรับแค่ชื่อและขนาด ไม่เก็บไฟล์), ผูกคลิปกับช่อง |
| ตอบอัตโนมัติ | ตั้งค่า AI ตอบแชท และกด “ทดลองตอบ” ได้คำตอบตัวอย่าง |
| ยอดขาย | GMV รายบัญชีย้อนหลัง 30 วัน และส่งออก Excel รายเดือน |
| Live Session / Product Set | เลือกวิดีโอ ตั้งชื่อห้อง จัดการชุดสินค้า |
| ผู้ใช้ Live Hub | เพิ่มผู้ใช้ มอบหมายบัญชีให้ทีมงาน |

## สิ่งที่ถอดออกจากระบบจริง

- การเชื่อมต่อ TikTok ทั้งหมด: สร้าง/ปิดห้อง LIVE, ดึง stream key, ตรวจ session, ลายเซ็นคำขอ
- การอ่านและแก้ตะกร้า TikTok Shop, การดึงยอดขาย และตัวช่วยดึงข้อมูลบนเครื่องผู้ใช้
- ตัวส่งวิดีโอ (ffmpeg/RTMP), worker, ฐานข้อมูล PostgreSQL และ Redis
- การเรียก AI จริง, ส่งแชทเข้าไลฟ์, แจ้งเตือน LINE และระบบควบคุมมือถือ Boxphone
- สคริปต์ deploy, การตั้งค่าเซิร์ฟเวอร์ และค่าลับทั้งหมด

ในเวอร์ชันนี้ ทุกคำขอของหน้าเว็บไปจบที่ API จำลองใน [`lib/demo/api.ts`](lib/demo/api.ts)
โดยใช้ข้อมูลจาก [`lib/demo/store.ts`](lib/demo/store.ts) ชื่อร้าน สินค้า และตัวเลขทั้งหมดเป็นข้อมูลสมมติ

## โครงสร้าง

```text
app/            หน้าเว็บ (App Router) และ API จำลอง app/api/[...path]
components/     หน้าจอแต่ละส่วน เช่น CyberShell, LiveBasketPanel, SalesPanel
lib/demo/       API จำลองและข้อมูลตัวอย่าง
lib/auth.ts     ล็อกอินแบบตัวอย่าง (ไม่ใช้กับงานจริง)
```
